--- 6. ROW-LEVEL SECURITY: CONSENT AS AN ENGINE-ENFORCED FILTER -----

Regression guard. An earlier revision of this schema had the consent
policy present in DDL but INERT at runtime: the masked view executed as
its owner, the owner is a superuser, and superusers bypass RLS. All four
rows were visible. The fix was security_invoker=true on the view plus
COLUMN-level grants on the base table. This block pins that fix.

Rows in base table            : 4
Rows with consent_analytics   : 2

Result   : RLS ENFORCED — non-consented rows unreachable ✔

applied by the engine before the query is evaluated.
